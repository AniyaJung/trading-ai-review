# 交易研究

这套功能根据[用户提供的讨论](https://chatgpt.com/share/6ac6df94-5680-83ec-a34e-8491b4622eb8)实现“主观判断 → 交易事实与证据 → 条件统计 → 逐笔复查”的工作流。对话中的收益数字、样本数和 AI 替代时间是举例或预测，不作为软件验证结论。

## 开始使用

1. 保存一笔已平仓交易，在详情打开“研究记录”页签。
2. 先标记实盘/模拟/回放、原始判断来源、研究阶段、Setup 和信心。没有原始笔记时保持“事后回忆 / 补录”。
3. 按需要补充市场环境、订单流、盘口事件与管理结果，点击“保存研究记录”。
4. 打开“研究”，展开高级筛选后，例如筛选 ES、高波动、Ask 侧吸收，并按 Setup 或信心分组。
5. 看每组笔数和 R、MAE/MFE 的覆盖笔数，再展开“逐笔回看”检查原始交易与截图。返回研究页面时保留筛选条件。
6. 导出筛选样本 CSV，在其他研究工具中使用。导出仅保存到本机，不调用外部 AI。

## 六个记录维度

| 维度 | 内容 | 数据来源 |
| --- | --- | --- |
| 样本与判断 | 实盘/模拟/回放、判断来源、探索/验证/前向、Setup、信心、预期方向与窗口、触发与失效条件 | 人工记录 |
| 市场环境 | 时段、趋势/震荡/过渡、波动、方向偏见、VWAP 位置与距离、ATR、新闻、关键位置 | 人工记录与平台读数 |
| 订单流与响应 | 平台、观察窗口、Delta 口径、Volume、Bid/Ask 成交、累计 Delta、价格变化、吸收/衰竭、POC/VAH/VAL | 平台读数与人工观察 |
| DOM 事件 | 补单/撤单/加单/扫单、Bid/Ask 挂单深度、统计档数、价差、证据 | 盘口观察 |
| 管理与执行 | MAE/MFE、滑点、是否移动止损/止盈、分批退出、离场反思 | 成交记录与持仓期间数据 |
| 个人状态 | 精力、压力、情绪和执行偏差 | 人工记录 |

所有字段均为可选。输入为空表示未知，不转成 0、“否”或“未观察到”。当前没有交易平台接入，也不会从截图自动生成精确读数。所有研究字段保存在独立记录中，不改写交易事实、AI 确认状态或人工文章。

## 数值口径

- Delta 可能采用 Ask − Bid 或 Bid − Ask，必须核对平台设置。数值筛选要求选择相同计算口径和观察窗口；平台来源也可单独筛选。
- Bid/Ask 成交量与 DOM 挂单深度分别记录。挂单、补单或吸收标签不能证明特定参与者的意图。
- “窗口内价格变化” = 窗口末价 − 窗口初价，与做多/做空方向无关。
- “距 VWAP” = 当前价 − VWAP，可为负；筛选上限使用绝对点数。
- ATR、Profile、成交量和深度统计必须在观察窗口中注明周期、范围与档数，避免把不同测量口径视为同一条件。
- MAE/MFE 为持仓期间相对入场价的最大不利/有利变动，输入非负点数；做空时仍按不利/有利定义。没有持仓期间价格数据时留空，不能从最终盈亏推算。
- 滑点记录相对计划成交价的总 ticks，不利为正，价格改善为负。净盈亏已使用实际成交价并扣手续费，研究计算不会重复扣滑点。
- 原有交易模型仍是单次平均入场/出场。分批退出字段只是管理标记，不会创建多次真实成交或重新计算分批收益。

## 统计与验证边界

研究列表包括全部交易事实，不需要有 AI 草稿。只有已经保存且非空的研究记录进入条件分组；尚未填写的交易数量单独显示。未保存草稿不进入统计或导出。

分组总是分别计算品种、交易来源、判断来源和研究阶段。净盈利占比使用净盈亏 > 0 的笔数除以全部组内交易，保本交易留在分母。平均净 R 使用已有的扣费 R；R、MAE、MFE 缺失时排除并显示有效数据笔数。不能把小样本的高胜率或平均 R 当作确定优势。

“入场前笔记”和“持仓中笔记”表示用户声明已有外部原始记录。软件保存时间独立记录，当前应用仅录入已平仓交易，所以这些标签不能证明判断确实在事前作出。研究阶段同样是用户标签，允许编辑，不构成不可修改的样本外验证。

预期方向、观察窗口、交易最终盈亏是不同对象。没有对应窗口的后续价格数据时，软件不会把盈利直接当成预期方向命中，也不计算事件研究的前向收益。

当前功能是实际录入样本的描述性统计。只录入已交易机会、事后回忆、多次筛选和人工标签都可能带来偏差；自动 Tick/MBO 采集、未交易机会记录、规则冻结、历史成交模拟和严格样本外验证需要独立数据与后续工作。

## 数据保存

数据库 v6 为每笔交易保存一条 `trade_research` 记录，完整备份和恢复自动包含它。删除交易同时删除其研究记录。界面草稿按交易保留在当前应用会话内；关闭应用前必须保存。保存期间继续编辑会保留新编辑，并明确显示仍有未保存修改。

单笔 AI 复盘会接收已经保存的研究记录。Prompt v3 要求 AI 把人工观察与假设和可核对事实分开，不臆造精确读数，不从单笔结果声称统计优势。AI 功能仍在用户主动点击生成时调用配置的接口。
